#IP Addresses

## What i learned 
An IP address is a number that identifies a device on a network 

## What i did
Ran "ipconfig /all" on my PC while connected to my phones hotspot

## Key takaways
Every device on a network needs it's own IP address.
An IP address tells other devices where to send data.
To know if you're on the same network your devices address and the default gateway shares the same first three numbers.
